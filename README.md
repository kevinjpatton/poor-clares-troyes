# Poor Clares of Troyes

A bilingual (English / French) website for the Poor Clares of Perpetual
Adoration, Monastère Notre-Dame des Anges, Troyes, France.

Plain HTML, CSS and JavaScript: no build step. Open `index.html` through
any static web server to view it.

## Updating the site

- **News (about quarterly):** edit `data/news.js`. Instructions are at the
  top of that file. News photos go in `assets/images/news/`.
- **Any other text, emails, phone, PayPal links:** edit `data/content.js`.
  French lines marked `// TR` were translated and should be checked by the
  sisters.

See `spec.md` for the full design and its open questions.
